# Administración — primera entrega

Aplicación Angular independiente para acceso con MFA, perfiles, bandeja de solicitudes, asignación, invitaciones, reportes agregados y auditoría. Disponible bajo `/admin/` a través del servicio web.

La edición y publicación de contenidos del CMS siguen pendientes. La pantalla del Editor lo indica expresamente.

Consultar [activación y operación](../../docs/ADMINISTRACION.md), [decisiones](../../docs/DECISIONES.md) y [arquitectura](../../docs/ARQUITECTURA.md).

Desarrollo: `npm ci`, `npm start`. Compilación: `npm run build`. No hay credenciales predeterminadas ni autorregistro.
